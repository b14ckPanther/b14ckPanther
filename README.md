<h2>HOW I THINK</h2>

<br/>

<pre>
PRODUCT
   ↓
EXPERIENCE
   ↓
SYSTEM DESIGN
   ↓
DATA + SECURITY
   ↓
IMPLEMENTATION
   ↓
POLISH
   ↓
SHIP
</pre>

<p>
I like software where <strong>product thinking and engineering happen together</strong>.

designing the system before accumulating features, and polishing the experience
